# Design system

What the UI must look and behave like. Frontend builds against it. Validator reviews code (Standards axis) and screenshots against it. Facts and rules only, each with the `path:line` of the token or component it comes from; no aspirations. Verified against 562e1303 2026-10-29.

LCARS look, distilled from `lcars-reference-files/` (reference kit, not built, never edited: `README.md:371-375`, `eslint.config.mjs:6`). Plain per-component `.css` files imported by their component; no Tailwind, CSS modules or UI kit (`package.json:15-33`). Global CSS loads in order fonts → theme → global (`src/main.tsx:5-7`).

## Components
- `Panel` (`src/components/common/Panel.tsx:5-27`): grid-area panel with elbow + title bar in the accent color and a scrolling body (`src/components/common/Panel.css:1-43`). Use for the fixed dashboard areas (FleetList, SystemMap, ShipDetailPanel, ChatStub: `src/components/fleet/FleetList.tsx:24`, `src/components/map/SystemMap.tsx:138`, `src/components/shipDetail/ShipDetailPanel.tsx:184,211`, `src/components/chat/ChatStub.tsx:38`). Accent prop takes the `Accent` type but `src/components/common/Panel.css:45-59` defines only orange, tan, lavender, blue, violet; green/yellow/red leave `--accent-color` unset.
- `PillButton` (`src/components/common/PillButton.tsx:5-31`): most labelled action buttons; exceptions are the knob Save, a plain `<button>` (`src/components/knobs/KnobRow.tsx:71`), and the alert dismiss, class `lcars-alert__dismiss` (`src/components/layout/AlertBanner.tsx:16`); `accent` picks the fill from all 8 accents (`src/components/common/PillButton.css:23-46`); disabled = `#3a3a3a` fill + dim text (`src/components/common/PillButton.css:18-21`); `title` carries the reason a control is disabled (e.g. `src/components/map/WaypointPopover.tsx:108-114`, `src/components/shipDetail/MarketList.tsx:47`). Icon-only close/zoom buttons are plain `<button>`s with their own `lcars-*__close` / `lcars-map__control` class.
- `StatusPill` (`src/components/common/StatusPill.tsx:9-12`): ship nav status DOCKED / IN_ORBIT / IN_TRANSIT, anything else `status-unknown` dim.
- `QueryState` (`src/components/common/QueryState.tsx:34-62`): what a panel says with no data (see Interaction).
- `Accent` type (`src/components/common/accent.ts:2`); its comment says the classes live in src/styles/theme.css, they live in `src/components/common/Panel.css:45-59` and `src/components/common/PillButton.css:23-46`.
- `TogglePanelProps` (`src/components/common/TogglePanelProps.ts:4-7`): `{ onClose, style }` every toggled overlay panel takes.
- Alerts: `pushAlert(message, { severity, sticky, timeoutMs })`, default error, 6 s auto-dismiss (`src/context/AlertProvider.tsx:20-24`), drawn by `AlertBanner` fixed top-center (`src/components/layout/AlertBanner.css:1-11`). Every mutation's `onError` reports through it (e.g. `src/components/autopilot/AutopilotPanel.tsx:38`, `src/components/shipDetail/ShipDetailPanel.tsx:73`).

## Layout and style rules
- Every class is `lcars-<block>[__element][--modifier]`. Holds: 246/250 CSS class selectors carry an `lcars-` class, 189/189 static `className` tokens start `lcars-` (verified 2026-10-29 @ 562e1303 by script over `src/**/*.css` and `*.tsx`). The 4 exceptions are the bare `.status-docked`, `.status-in-orbit`, `.status-in-transit`, `.status-unknown` (`src/components/common/StatusPill.css:12-23`). Runtime state modifiers `is-*`, `status-*`, `mode-*` are compounded on an `lcars-` class (`src/components/fleet/FleetList.css:34`, `src/components/map/SystemMap.css:35`, `src/components/autopilot/AutopilotPanel.css:56`). `lcars-*` names are effectively public: DOM smoke tests select `.lcars-map__waypoint` / `.lcars-map__ship` (`CLAUDE.md:227`).
- App shell: one screen, no router (`src/App.tsx:8-10`). `html, body, #root` are 100% high with `overflow: hidden` (`src/styles/global.css:5-11`); the dashboard is a grid agentbar / fleet·map·detail / chat, columns 18rem · 1fr · 22rem, rows 3.5rem · 1fr · 12rem (`src/components/layout/Dashboard.css:1-14`). Panels scroll inside their body (`src/components/common/Panel.css:38-43`), never the page.
- One breakpoint: ≤1100px reflows to two columns and lets the dashboard scroll (`src/components/layout/Dashboard.css:36-47`). No other media query.
- Toggle panels (Contracts, Autopilot, Observability, Knobs) are `position: absolute; top: 4.5rem; z-index: 500` overlays with an accent-filled header holding an `h2` and a `×` close button (`src/components/contracts/ContractsPanel.css:1-35`, `src/components/contracts/ContractsPanel.tsx:92-98`). Adding one = 4 edits: `PANEL_ORDER` `src/utils/togglePanelLayout.ts:6`, `PANEL_WIDTH_REM` `:11-16`, `PANEL_BUTTONS` `src/components/layout/AgentBar.tsx:13-18`, render branch `src/components/layout/Dashboard.tsx:42-45`. The panel's CSS `width` equals its `PANEL_WIDTH_REM` entry (4/4 match: `src/components/contracts/ContractsPanel.css:5`, `src/components/autopilot/AutopilotPanel.css:8`, `src/components/observability/ObservabilityPanel.css:8`, `src/components/knobs/KnobEditor.css:5`); nothing enforces it.
- Stacking: toggle panels 500, alert stack 1000 (`src/components/layout/AlertBanner.css:6`).
- Map: everything sized in screen pixels goes through `screenToLocal` / `iconLocalSize` (`CLAUDE.md:114-117`); paint order OrbitRing → TransitPath → Waypoint → Ship → Label (`CLAUDE.md:195`).

## Interaction
- No-data states: a panel list query renders through `QueryState`, which keeps four answers distinct: loading → "Loading…", rejection → the error message in red (fallback "Request failed"), `null` → `notConfigured` (route 404'd, feature off), `undefined` → `empty` (query never ran, e.g. signed out) (`src/components/common/QueryState.tsx:16-61`, tests `src/components/common/QueryState.test.tsx:12-47`). Used by `src/components/fleet/FleetList.tsx:25`, `src/components/contracts/ContractsPanel.tsx:99`, `src/components/knobs/KnobEditor.tsx:76`, `src/components/observability/ObservabilityPanel.tsx:28`. Exceptions that render their own "none" line for an undefined query: `src/components/shipDetail/MarketList.tsx:21-24`, `src/components/shipDetail/CargoList.tsx:35-39`. The API side: `allow404` maps 404 → `null` (`src/api/client.ts:31-47`).
- An unavailable stat reads "—", a pending one "…", never blank (`src/components/layout/AgentBar.tsx:20-26,42-44`).
- Missing scope: controls render disabled, never hidden (`src/components/autopilot/AutopilotPanel.tsx:20-24`, `src/App.tsx:3-7`). Every `fleet:control` action ANDs `!hasControl` into `disabled` (`src/components/shipDetail/ShipDetailPanel.tsx:219-317`, `src/components/contracts/ContractsPanel.tsx:89`, `src/components/map/WaypointPopover.tsx:107,124`, `src/components/autopilot/AutopilotPanel.tsx:91,97,111,114`); knob edits AND `!canAdvise` (`src/components/knobs/KnobEditor.tsx:100`). Autopilot and Knobs panels add a one-line reason, signed-in vs signed-out wording (`src/components/autopilot/AutopilotPanel.tsx:102-108`, `src/components/knobs/KnobEditor.tsx:69-75`). Scope check is client-side and optimistic; the server re-checks (`src/context/OperatorContext.ts:7-11`).
- Spend confirmation: purchases are two-step, "Buy" opens a row, the second button names the total, "Confirm (Ncr)" (ship: `src/components/map/WaypointPopover.tsx:115-129`; cargo: `src/components/shipDetail/MarketList.tsx:48-70`), disabled with title "Not enough credits" when unaffordable (`src/components/map/WaypointPopover.tsx:98,124-125`, `src/components/shipDetail/MarketList.tsx:36,63-64`). Sell / deliver / transfer open a units row then a plain "Confirm" (`src/components/shipDetail/CargoList.tsx:80-156`). Single click, no confirm: refuel, navigate, extract, survey, orbit, dock, flight-mode select (fires on change), contract accept/fulfill, autopilot arm/pause/abort, knob Save (`src/components/shipDetail/ShipDetailPanel.tsx:220,241-289`, `src/components/contracts/ContractsPanel.tsx:46,54`, `src/components/autopilot/AutopilotPanel.tsx:80-116`, `src/components/knobs/KnobRow.tsx:62-74`).
- While any mutation in a panel is pending, its actions disable (`src/components/shipDetail/ShipDetailPanel.tsx:196-208`, `src/components/autopilot/AutopilotPanel.tsx:51`); in-flight labels read "Purchasing...", "Navigating...", "Loading..." (`src/components/map/WaypointPopover.tsx:75,128`, `src/components/shipDetail/NavigatePicker.tsx:39`).
- Mutation sequence: call with `await getToken()` → invalidate affected keys from `src/hooks/queryKeys.ts` → `pushAlert` on error (`src/components/autopilot/AutopilotPanel.tsx:33-39`; invalidation table `CLAUDE.md:206-213`).
- Knob input: out-of-range or empty draft marks the input `is-invalid`, shows "Must be a number between min and max", disables Save; a poll never overwrites an unsaved draft (`src/components/knobs/KnobRow.tsx:8-15,31-33,69-79`).
- Map: wheel, drag, and keyboard arrows / `+` / `-` / `0` on the focusable SVG (`src/hooks/useMapViewport.ts:200-221`, `src/components/map/SystemMap.tsx:152`); never `setPointerCapture` in `pointerdown` (`CLAUDE.md:123-127`).

## Accessibility baseline
- Demonstrated: all controls are native `<button>`, `<select>`, `<input>` (`src/components/common/PillButton.tsx:21`, `src/components/fleet/FleetList.tsx:33`); the map SVG takes `tabIndex={0}` with a `:focus-visible` blue outline (`src/components/map/SystemMap.tsx:152`, `src/components/map/SystemMap.css:23-30`); `aria-label` on the alert dismiss and map zoom buttons (`src/components/layout/AlertBanner.tsx:18`, `src/components/map/MapControls.tsx:28,39,49`); disabled controls explain themselves via `title` (see Components).
- Gaps in today's code: panel/popover `×` close buttons have no `aria-label` (`src/components/autopilot/AutopilotPanel.tsx:63`, `src/components/contracts/ContractsPanel.tsx:95`, `src/components/knobs/KnobEditor.tsx:65`, `src/components/observability/ObservabilityPanel.tsx:47`, `src/components/map/ShipPopover.tsx:50`, `src/components/map/WaypointPopover.tsx:64`); inputs and selects have no `<label>` (`src/components/shipDetail/MarketList.tsx:55`, `src/components/knobs/KnobRow.tsx:63`, `src/components/shipDetail/CargoList.tsx:110,120,129`); waypoints and ships are pointer-only `<g onClick>` (`src/components/map/layers/WaypointLayer.tsx:64-71`, `src/components/map/layers/ShipLayer.tsx:52`); no global focus style.
- Minimum for new UI: keyboard-reachable controls, visible focus, contrast AA, a label or `aria-label` on every input and icon-only button (aspiration: not checked against code) (unverified).
