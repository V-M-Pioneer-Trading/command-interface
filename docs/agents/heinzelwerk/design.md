# Design system

What the UI must look and behave like. Frontend builds against it. Validator reviews code (Standards axis) and screenshots against it. Facts and rules only; no aspirations.

## Direction

- The look is **LCARS**: the retro-futuristic Star Trek operator console. Black background, saturated flat colour blocks, rounded elbows and pills, condensed uppercase type. Source assets: `lcars-reference-files/`.
- The design is being reworked. Tokens, components and layout rules are not fixed yet, so this file holds only the direction. Until it holds more, build with what `src/styles/theme.css` and `src/components/common/` offer today, and keep new work inside the LCARS look.
